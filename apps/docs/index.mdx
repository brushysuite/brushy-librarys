Welcome to the official documentation for **Brushy Suite**, a modular toolkit for building typed, testable applications across web, mobile, and server runtimes.

**AI agents:** read [`/SKILL.md`](/SKILL.md) before generating code. It contains mandatory rules for DI, storage, and React patterns.

## MCP server

Connect AI tools to this documentation from the contextual menu in the page header. Use **Connect to Cursor**, **Connect to VS Code**, or **Copy MCP server URL** to add the hosted MCP endpoint. When deployed on Mintlify, the server is available at `https://<your-site-url>/mcp`.

## Quick install

```bash
npm install @brushy/di
npm install @brushy/storage @brushy/storage-react
```

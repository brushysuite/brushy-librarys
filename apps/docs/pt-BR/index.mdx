## Servidor MCP

Conecte ferramentas de IA a esta documentação pelo menu contextual no cabeçalho da página. Use **Conectar ao Cursor**, **Conectar ao VS Code** ou **Copiar URL do servidor MCP**. Quando publicado na Mintlify, o endpoint fica em `https://<url-do-site>/mcp`.

## Instalação rápida

```bash
npm install @brushy/di
npm install @brushy/storage @brushy/storage-react
```

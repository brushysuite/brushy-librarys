O `@brushy/storage` oferece uma API no estilo NodeCache que funciona em Node, navegador e contextos SSR. Adaptadores de persistência opcionais gravam em `localStorage` ou `sessionStorage`, e um bus de invalidação integrado mantém abas sincronizadas quando instâncias compartilham o mesmo `id`.

Os bindings React ficam em [**@brushy/storage-react**](/storage/react-hooks) (pacote separado).

## Instalação

```bash
npm install @brushy/storage

# Hooks React (pacote separado)
npm install @brushy/storage-react react
```

## Exemplo rápido

```typescript
import { createStorage } from "@brushy/storage";

const cache = createStorage({
  id: "my-app",
  stdTTL: 0,
  checkperiod: 600,
  prefix: "@myapp:",
  persist: "local",
});

cache.set("session", { token: "abc" }, 3600);
cache.get("session");
cache.del("session");
```

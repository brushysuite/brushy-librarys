# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

Email **contact@gfrancodev.com** with:

- Package name (`@brushy/di`, `@brushy/di-core`, etc.)
- Steps to reproduce
- Impact assessment

We aim to respond within 7 days.
